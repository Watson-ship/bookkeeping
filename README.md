# 📱 记账小助手（手机记账软件）

一个**纯前端**的手机记账应用，无需服务器、无需数据库，可直接部署到 **GitHub Pages** 免费使用，并可以「安装」到手机桌面像 App 一样使用（支持离线打开）。

## ✨ 功能一览

| 页面 | 功能 |
| --- | --- |
| 📝 每日记账 | 记一笔：日期、物品、单价、数量（**可带单位**）、总价、使用天数；**同物品自动累计**；实时显示**当日 / 本周 / 本月 / 本年支出** |
| 📊 花费占比 | 内嵌在记账页：饼图展示当日 / 本周 / 本月 / 本年的花费占比，一眼看出**消费大头** 👑 |
| 💹 价格对比 | **同名物品自动合并**，展示每次价格变化（默认收起，点开看全部）；最新价格涨跌 ▲▼ |
| 📦 剩余天数 | 按**单条记账记录**计算剩余天数（同名各自独立），绿黄红进度条；未设置使用天数的不显示，剩余不足 1 天自动移除 |

## 🚀 一、部署到 GitHub（网页版操作，最简单）

1. **注册并登录** [GitHub](https://github.com)（没有账号先免费注册一个）。
2. **新建仓库**：点右上角 `+` → `New repository` → 仓库名填 `jizhang` → 选择 **Public**（公开，否则手机无法访问）→ `Create repository`。
3. **上传文件**：进入仓库页面，点 `Add file` → `Upload files` → 把本项目**全部 9 个文件**拖进去 → 下方点 `Commit changes`。
4. **开启 Pages**：仓库页点 `Settings` → 左侧 `Pages` → `Build and deployment` 下 `Source` 选择 **Deploy from a branch** → `Branch` 选择 **main** 和 **/(root)** → `Save`。
5. **等待 1~2 分钟**，访问：
   ```
   https://你的用户名.github.io/jizhang/
   ```
   手机浏览器打开这个网址即可使用。

> 如果第 3 步上传时 `.nojekyll` 等以点开头的文件看不到，请确认文件管理器里「显示隐藏文件」已打开，或直接上传其余 8 个文件也不影响使用。

## 💻 二、部署到 GitHub（git 命令方式）

```bash
# 1. 在 GitHub 网页上新建仓库 jizhang（Public）后执行：
git clone https://github.com/你的用户名/jizhang.git
# 2. 把本项目所有文件复制进 jizhang 文件夹
# 3. 提交并推送
cd jizhang
git add .
git commit -m "记账小助手"
git push
```

然后按「一」中第 4 步开启 Pages 即可。

## 📲 三、安装到手机桌面（相当于"下载"）

- **安卓**（Chrome / Edge 浏览器）：打开网址 → 点浏览器菜单 `⋮` → **安装应用 / 添加到主屏幕**。
- **iPhone**（Safari）：打开网址 → 点底部**分享按钮** → **添加到主屏幕**。

之后从桌面图标打开，全屏运行，**打开过一次后断网也能用**。

## 💾 四、数据说明（重要）

- 所有数据保存在**手机浏览器本地**（localStorage），**不联网、不上传任何服务器**，纯本地记账。
- 换手机、清除浏览器数据会导致数据丢失。请定期使用应用内 `⚙️ 设置 → 导出数据` 备份，新设备用 `导入数据` 恢复。
- 电脑上也可以直接用浏览器打开 `index.html` 试用。

## 🔄 五、更新版本

修改文件后重新上传覆盖（或 git push）即可。如果手机打开的还是旧版本，把 `sw.js` 里的 `CACHE = 'jizhang-v1'` 改成 `'jizhang-v2'`（每次更新加 1）再刷新两次即可。

## 🛠 常见问题

- **总价怎么填？** 「记一笔」里的总价 = 实际花费。填了单价和**纯数字数量**时，总价会自动 = 单价 × 数量；数量带单位（如 `3瓶`、`500ml`）时请手动填总价。
- **价格对比怎么用？** 不用单独维护：在「记账」页记一笔并填总价，价格页会自动按**物品名称合并**并记录每次价格变化；记录默认收起，点「价格记录」展开。
- **记账的四个数字是什么？** 记账页顶部「当日 / 本周 / 本月 / 本年」是按**今天**统计的支出总额；下方明细按表单里选择的日期显示。
- **剩余天数怎么算？** 记一笔时填写「使用天数」，库存页从该笔记账日期开始计算剩余天数并画进度条，剩余 ≤3 天会预警。
- **相同物品会合并吗？** 会。价格页和库存页都按**物品名称自动合并**，同名物品只有一张卡片；删除卡片会同时删除该物品的全部记账记录。
